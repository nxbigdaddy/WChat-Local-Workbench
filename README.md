# 微信本地工作台

Python / PySide6 桌面工具，用于浏览当前电脑微信的联系人缓存与聊天记录。

双击 `start.bat` 启动，或在此目录运行：

```powershell
python app.py
```

先登录电脑微信，然后点击“读取当前微信”。选择联系人，点击“读取聊天”；输入关键词可搜索该联系人的本机记录。“加载更早记录”按时间向前翻页，每页 100 条，单个视图最多 2,000 条。首次读取较大的聊天数据库约需几十秒；进度显示在底部，可以取消。

## 当前功能

- 通讯录：昵称、微信备注、微信号/内部标识；搜索与群聊、有备注、备注待核对筛选。
- 聊天：跨本机 `message_N.db` 分库查询、文字和压缩正文解码、发送者与时间、关键词搜索、分页。
- 非文本消息：显示图片、语音、视频、文件等类型；尚不打开媒体附件。公众号的独立消息库尚未纳入查询。
- 备注：**辅助修改流程**，编辑并保存本地草稿、复制新备注，在微信里修改并保存，再点击“刷新并核对备注”。只有读取到同一联系人备注与草稿一致才显示“核对一致”；这不等于手机端或服务器同步已验证。

**当前版本不提供自动写回微信备注。** 本机微信窗口未暴露可用的业务控件；已有第三方 UI 自动化接口也依赖这些控件。功能现状、源码依据见 [备注写入调查](docs/remark_write_feasibility.md)。修改解密副本不会更新微信，因此本工具不采用这种写入方式。

## 本机读取范围

已在 Windows、Python 3.12.8、微信 **4.1.13.65** 上验证。需要本机微信保持登录；本次无需连接 iPhone。只绑定正在使用的账号，多个账号无法唯一识别时停止。读取微信进程和数据库均为只读，不修改源数据库。

通讯录里的条数是缓存实体数，包含群聊、公众号、历史联系人等，**不能当作好友数**。聊天范围限于当前电脑已保存且能验证的分库，不保证包含手机全部历史或已删除记录。

密钥和解密数据库只保存在本进程内存中；退出时释放。程序不提供联网请求、消息发送或遥测。只会持久保存用户自己编辑的备注草稿：

```text
%LOCALAPPDATA%\WChatDesk\remark-drafts.json
```

草稿包含账号标识、联系人标识、旧备注、新备注及核验状态。草稿旁的 `.lock` 文件用于避免并发写入。损坏草稿不会被静默覆盖；草稿问题不阻断通讯录读取。演示模式的草稿使用临时目录。

默认单库上限 320 MiB、WAL 上限 64 MiB、明文内存缓存上限 384 MiB。读取大库时瞬时内存可能约 1–2 GiB。关键词搜索每次上限 100,000 行或 180 秒；超限、分库读取失败、正文解码失败会在界面明确提示，可点击“读取详情”查看原因。未完成扫描不提供可能跳过记录的翻页游标。

数据库与 WAL 副本重复读取校验，验证提交边界、页 HMAC、SQLite 完整性。读取期间没有持有微信自身的数据库事务锁，因此仍属于尽力取得的本机快照。

## 环境与演示

当前电脑已经具备依赖。其他环境可安装：

```powershell
python -m pip install -r requirements.txt
python app.py --demo
```

`--demo` 中所有联系人和消息均为虚构。微信安装位置目前在 `tools/verify_wechat_contacts.py` 的 `EXE` 常量配置；当前值为 `C:/Program Files/Tencent/Weixin/Weixin.exe`。该版本适配经过验证，后续微信更新可能需要调整。

## 验证

```powershell
python -m unittest discover -s tests -v
python -m unittest discover -s tools -p test_wechat_wal.py -v
python tools/check_gui.py
```

合成 GUI 检查使用 Windows 原生 Qt 窗口，生成不含真实个人数据的 `reports/gui-demo.png`。实际读取聚合结果在 [gui-reader-live.json](reports/gui-reader-live.json)，实际界面读取结果在 [gui-live-ui.json](reports/gui-live-ui.json)，不包含联系人、聊天正文或密钥。详见 [验收记录](reports/GUI验收记录.md)。

界面源码在 `wchat/gui.py`，读取后端在 `wchat/reader.py`，本地草稿在 `wchat/drafts.py`。**本仓库不打包任何第三方 CLI**：程序启动不导入、不调用外部项目代码。上游参考项目的提交号、许可证与适配说明见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) 及 `licenses/`。
