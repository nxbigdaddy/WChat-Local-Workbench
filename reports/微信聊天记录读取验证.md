# 微信聊天记录读取验证

实测时间：2026-09-11 01:53（北京时间）。客户端：Windows 微信 4.1.13.65。

## 结论

已通过实际运行确认：当前账号的一个本地消息分库可以只读解密、查询并解码文字消息。无需连接 iPhone。

## 实测证据

| 项目 | 结果 |
|---|---|
| 当前账号绑定 | 由运行中微信打开的数据库文件路径确认 |
| 消息分库 | 检测到 3 个；按文件及 WAL 修改时间选取 `message_2.db`（20 MiB）进行抽验 |
| 密钥验证 | passed：目标消息库首页 HMAC 校验通过 |
| 数据页校验 | passed：2,746 个非零页面通过 HMAC；其余 2,374 页全零 |
| 增量日志 | 9 个连续有效帧、2 次提交，应用 7 个最新页面；后续 salt 不匹配处停止 |
| SQLite 完整性 | passed：`integrity_check = ok` |
| 消息表及记录 | 所选分库含 98 张消息表、11,650 条消息，其中 7,811 条文本 |
| 文本解码抽验 | passed：20/20；含 7 条 Zstandard 压缩文本，使用严格 UTF-8 解码 |

98 张消息表不等同于整个账号的会话总数；11,650 条也不是全部聊天记录数。

## 执行范围与局限

- 仅验证一个当前账号的消息分库及其 WAL；未遍历或导出全部聊天正文。
- 抽验正文仅在探针进程内存中解压和解码。没有向终端、报告或其他文件输出正文。
- 密钥及解密数据库没有持久化；未修改微信文件、联系人或消息，没有发送消息。
- 探针不联网，不访问图片、语音、附件或外部链接。
- 主库和 WAL 各读取两遍并逐字节比较，同时验证文件元数据稳定；没有取得 SQLite 读事务锁，因此不宣称实时事务快照。
- 其他分库、手机上未同步到电脑的历史、媒体内容可用性及完整历史覆盖均未验证。

## 复现文件

- `tools/verify_wechat_messages.py`：本次限定范围的验证入口。
- `reports/wechat-messages-verification.json`：机器可读实测结果。
- 共用 `tools/verify_wechat_contacts.py` 中已审查的只读内存扫描与页面验证函数，以及 `tools/wechat_wal.py`。

运行：`python tools/verify_wechat_messages.py`。脚本只输出结构与统计；每次重新绑定当前账号和校验目标库密钥。

按联系人、群和时间范围实际读取时，需要进一步确认目标会话，并查询该会话可能分布的各个消息库。
